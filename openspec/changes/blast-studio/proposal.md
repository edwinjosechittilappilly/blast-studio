# Proposal

## Why

Market Blaster safely publishes but does not create and review platform-native media from diverse sources. Blast Studio provides an isolated, evidence-grounded production workflow with explicit policy, rights, cost and human-approval controls before handoff.

## What Changes

- Create a local CLI and file-based studio for anchored briefs, platform plans, editable assets, rendering and review.
- Add platform packs, sourced policy and format data, review gates and calibrated editorial scoring.
- Produce versioned Market Blaster handoffs and manual exports without publishing content.
- Add motion, optional media providers, bounded spending, source updates and a secure local dashboard across milestones M1–M3.

## Capabilities

### New Capabilities

- `content-inputs`: Ingest sources into an anchored, isolated brief.
- `content-generation`: Plan, make and render platform-native editable content.
- `content-review`: Gate, score, revise and accept content.
- `budget-and-providers`: Control provider access and account for spending.
- `export-handoff`: Hand reviewed content to Market Blaster or a human publisher.
- `platform-updater`: Track, propose and verify sourced platform data changes.
- `studio-dashboard`: Derive terminal and secure local dashboard views from studio files.

### Modified Capabilities

None.

## Impact

Introduces a Node-based CLI, local studio storage, platform packs, render and agent tools, provider integrations, and weekly updater CI. Market Blaster's separate `media-and-import` change supplies the import contract and media support. Publishing, analytics, voice cloning and website automation remain out of scope.
