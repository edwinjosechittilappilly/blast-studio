# Media generation stack

Research date: 2026-11-22. Prices are observed USD list prices, not quotes, and can change. [JUDGEMENT] marks recommendations; [UNVERIFIED] marks account access, support or rights not established here. No rendering benchmarks, paid generations or credentialed API calls were run. Source links accompany the relevant claims; a grouped source index is at the end.

## Decisions summary

- **Static cards and carousels:** [JUDGEMENT] use authored HTML/CSS templates and pinned Playwright/Chromium for PNG and print-to-PDF; use SVG and resvg for simple vector art. Alternatives: Satori + resvg, or Takumi when its CSS subset fits. Keep the actual text in deterministic layout, rather than asking an image model to spell it.
- **Images:** [JUDGEMENT] start with the owner's existing omp Codex/Antigravity image transport as an optional interactive experiment, not as a promised CI API. For unattended production choose a separately credentialed image API with a spending cap; evaluate Gemini and OpenAI against the same brief. Preserve the selected original and metadata; regenerate only explicitly.
- **Logos:** [JUDGEMENT] human/agent-edited SVG as source of truth; Recraft or Ideogram are optional exploration inputs, not proof of trademark clearance. Export square transparent PNGs and ICO, inspect at small sizes.
- **Diagrams:** [JUDGEMENT] use the already installed `arch-diagram` skill for structured architecture and Mermaid CLI for sequence/flow; Excalidraw's official CLI when a hand-drawn editable scene is wanted. Export SVG and attach explanatory text.
- **Motion:** [JUDGEMENT] Remotion + its official agent skills + FFmpeg is the default for reusable React-based social videos; HyperFrames is a strong HTML-first alternative and Motion Canvas is MIT-licensed. Use VHS for reproducible scripted terminal demos; capture actual UI interactions for screen recordings.
- **Cost and rights:** Remotion is not generally MIT: its free license covers individuals and companies of **up to three people**. API image use has provider-specific charges and terms. Recraft's API prohibits removing provenance markings and using assets to train AI; its developer terms also restrict competing services and automated request rates. See details before making it an embedded dependency. [Remotion pricing](https://www.remotion.dev/docs/license/pricing), [Recraft developer terms §§3, 6](https://www.recraft.ai/legal/developer-terms).
- **Publishing boundary:** generation is separate from publishing. Existing Market Blaster policy says no AI-generated HN text, and manual/outline-only handling for restricted communities; local Chromium rendering is not automation of a social website. [Existing plan](../../../market-blaster/docs/design/auth-and-reach.md), [HN guidelines](https://news.ycombinator.com/newsguidelines.html).

## Comparison conventions

**Mac/Linux** means a local tool can be installed on macOS and run on a Linux CI runner subject to runtime/browser/native dependencies; hosted APIs can be called from either over HTTPS, but credentials/network and the provider's terms are required. [UNVERIFIED] Exact arm64 binary availability and every specific CI image were not tested. **Reproducible** means stable source and pinned toolchain can produce visually repeatable results, not guaranteed byte-identical cross-OS files. Pin fonts, locale, time, browser, versions and assets; freeze random seeds, animation clocks and network responses. For generative services, save original result, input, model/version, parameters, timestamp, cost, and provenance: a seed is not a promise of identical future output. Render times below are qualitative [JUDGEMENT], not measured numbers; resolution, page count, frame count, renderer and hardware dominate.

Agent skill status is noted where verified; **[UNVERIFIED]** does not mean no skill exists. Source licenses below are not licenses for fonts, third-party assets, media outputs, model weights or hosted services.

### Existing access is not the same as an API key

The user reports ChatGPT/Codex and Claude Max subscriptions and an omp Google Antigravity provider. `omp models` was observed listing `openai-codex` and `anthropic` chat models; its `images` column alone is not proof of image *generation*, entitlement, CI access or working credentials. The command did **not** list an Antigravity section in this invocation; account-specific availability remains **[UNVERIFIED]**.

The local [omp generate_image documentation](omp://tools/generate_image.md) explicitly describes a feature-gated tool (`generate_image.enabled=true`, default false) with Codex subscription-backed hosted image generation, and an Antigravity internal image endpoint requiring an access token and project ID. Codex's backend chooses the image model; actual feature availability, quota, applicable subscription terms, cost, and suitability for unattended CI are **[UNVERIFIED]**. Those are not equivalent to a documented, separately billed developer API. Tool outputs are temporary files; persist selected files and metadata. No actual provider call was made.

[OpenAI](https://help.openai.com/en/articles/9039756-managing-billing-settings-on-chatgpt-web-and-platform) separates ChatGPT and API billing; eligible plans may have [API credit benefits](https://help.openai.com/en/articles/20001626-api-credits-benefit-for-eligible-chatgpt-subscriptions), so do not assume either zero credit or unlimited API. [Anthropic](https://support.claude.com/en/articles/9876003-why-is-claude-api-usage-billed-separately-from-my-paid-claude-plan) separates Claude and API billing; its [monthly API credits page](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-ultra-and-team-plans) lists **$100 for Max** subject to eligibility/activation, not a guarantee this owner activated it or that it provides any other vendor's image API. [UNVERIFIED] The available Claude plan provides a standalone image generation endpoint.

**Provenance is not permission.** C2PA is signed provenance metadata, not an invisible watermark; it can be removed by transformations. SynthID is an embedded watermark, not a guarantee of detection after all edits. Preserve provider originals, record transformations, avoid intentionally stripping marks, and check platform disclosure rules; rights, copyrightability, originality and trademark protection are distinct. [OpenAI](https://help.openai.com/en/articles/8912793-c2pa-and-synthid-in-openai-generated-images), [Google](https://deepmind.google/models/synthid), [Recraft terms](https://www.recraft.ai/legal/developer-terms).

## Video and motion

For all local renderers, Mac + Linux use is expected with the relevant Node/Python/native/browser dependencies; **[UNVERIFIED]** exact CI runners, codec builds and arm64 binaries. Arbitrary 9:16, 1:1 and 16:9 compositions are authorable or can be re-rendered at those dimensions; a crop is not equivalent to re-layout. [FFmpeg](https://ffmpeg.org/ffmpeg.html) can encode H.264 MP4, WebM and GIF when built with appropriate codecs; codec availability and licensing depend on the build. Keep a high-quality master, publish H.264 MP4 for compatibility where accepted, WebM when needed, and GIF only for short silent loops [JUDGEMENT].

### Captions, narration and music

- [OpenAI Whisper](https://github.com/openai/whisper) is MIT code and transcribes locally; review output and timing manually, then store SRT/VTT and optionally burn captions with FFmpeg. Runtime depends on model, device and recording length; no benchmark made. API alternatives incur usage charges; see [OpenAI pricing](https://developers.openai.com/api/docs/pricing). Accessible captions should include meaningful non-speech audio, not merely raw ASR [JUDGEMENT].
- Narration: use human voice by default [JUDGEMENT]. Local [Piper](https://github.com/OHF-Voice/piper1-gpl) is GPL; each voice/model's training-data license is separate, and its [commercial voice guidance](https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/COMMERCIAL_USE.md) must be checked. Alternatively use a provider's [speech API](https://developers.openai.com/api/docs/guides/text-to-speech) with separate metered cost and voice/disclosure requirements. Pin model and voice, but do not promise byte-identical synthesis across provider updates.
- Music: use no music unless useful [JUDGEMENT], or obtain a license covering commercial use, synchronization, every target platform, territories and duration. [YouTube Audio Library](https://support.google.com/youtube/answer/3376882) has track-specific attribution conditions; do not assume YouTube-specific rights extend to all social networks. Preserve license evidence and attribution; avoid unlicensed popular music.

## Owner decisions

1. Set monthly and per-job image budget, allow/deny hosted prompt and reference-image transmission, and choose paid API provider(s); decide whether subscription-backed omp generation is acceptable for interactive use only. Confirm actual credentials, quotas and entitlement without exposing secrets.
2. Decide whether locally generated SVG is sufficient for brand identity or budget for vector exploration and professional trademark/legal review. In particular, review Recraft's no-training, provenance, automation and competing-service restrictions before use.
3. Accept Remotion's license as a solo business and review eligibility if headcount or company structure changes; alternatively standardize on Apache-2.0 HyperFrames or MIT Motion Canvas. Determine whether later product use is an automator use under the then-current license.
4. Approve music/voice rights, AI disclosure, asset retention and network/privacy policy; choose human versus synthetic narration and which destinations may receive generative media.
5. Define actual output templates, formats, accessibility checks, document handoff versus API publishing, and CI budget; run a controlled render benchmark on the intended Mac and Linux runner before promising latency or byte-level reproducibility.
