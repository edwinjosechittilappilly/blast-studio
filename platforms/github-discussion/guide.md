Project-related promotion in a README is allowed when advertising is not its primary focus; bulk promotional activity and artificial stars/follows are prohibited. **[JUDGEMENT] Review seed:** (1) README identifies purpose and audience; (2) install/try instructions are runnable; (3) discussion has a clear topic/category; (4) release specifies version and meaningful changes; (5) claims link to commits/docs; (6) no artificial engagement and visuals have alternatives.
